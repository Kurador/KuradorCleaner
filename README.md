# Kurador Cleaner

App Android de limpieza profunda para dispositivos con root (KernelSU o Magisk).

## Requisitos
- Android 12+
- Root concedido con KernelSU o Magisk

## Descarga
La APK firmada se publica en GitHub Releases.

## Aviso
Usa acceso root y modifica archivos del sistema. No está pensada para Play Store.
